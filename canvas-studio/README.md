# 钛核 · 无限画布

一块无限大的白板：把图片、便签、文字拖上来，随便摆，最后导出 PNG。

## 操作

| 操作 | 方式 |
|---|---|
| 平移 | 空白处拖动 |
| 缩放 | 滚轮 / 工具栏 +/- |
| 添加 | 便签 / 文字 / 图片 |
| 编辑文字 | 双击节点 |
| 删除 | 选中后按 Delete |
| 适应视图 | 工具栏「适应」 |
| 保存 | 存到本机 localStorage 并导出 .json |
| 导出 | 导出 PNG（长图，自动裁切内容范围） |

## 场景

- 门店活动策划：把照片、卖点、时间、预算摆一块屏
- 内容排期：一周 7 张便签，拖来拖去
- 电商主图灵感板：把参考图拖进来拼

数据全在本地浏览器，不上传。
