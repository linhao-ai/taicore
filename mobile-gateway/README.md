# 钛核 · 手机访问

同一 WiFi 下，手机浏览器也能用电脑上的工作台。数据仍在本机，手机只是第二块屏幕。

## 使用

1. 双击 `启动手机访问.bat`
2. 浏览器自动打开二维码页面
3. 手机相机 / 微信扫一扫二维码
4. 手机浏览器里即可打开工作台
5. 用完点页面上的「停止」

## 原理

- 用 `dsh web --host <局域网IP> --port 8765 --no-open --trusted-host ...` 在局域网启动工作台
- 启动时打印带一次性 token 的访问地址，页面把它转成二维码
- token 每次启动都会变，重启后旧链接失效

## 安全

- 只监听局域网地址，公网访问不到
- 同一 WiFi 下的其他人如果拿到链接也能打开，公共 WiFi 慎用
- 建议用完即停；不要在咖啡厅/酒店 WiFi 长时间开启
