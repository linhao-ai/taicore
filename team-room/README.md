# 钛核 · AI 员工团队

给老板配一支不休息的 AI 团队：**9 个岗位角色 + 圆桌会议 + 单聊**。

## 预置员工

| 员工 | 岗位 | 擅长 |
|---|---|---|
| 🧭 店长阿May | 运营负责人 | 把目标拆成周计划 |
| ✍️ 文案小周 | 文案策划 | 钩子/利益/故事三版文案 |
| 🎨 设计阿哲 | 视觉设计 | 主图海报排版建议 |
| 💬 客服小林 | 客服主管 | 投诉处理与话术 |
| 🎬 导演老王 | 短视频编导 | 15 秒分镜脚本 |
| 📦 选品阿凯 | 选品定价 | 毛利/周转/价格带 |
| 📈 投流小陈 | 流量投放 | 预算分配与止损线 |
| 🧮 财务老李 | 财务成本 | 成本结构与算式 |
| 🎙️ 主持人 | 会议主持 | 汇总分歧与行动项 |

## 三种用法

1. **圆桌会议**：选 2-5 个员工 + 填议题 → 依次发言 → 主持人输出「共识/分歧/行动项/待拍板」
2. **单聊**：选一个员工，像微信一样聊
3. **员工管理**：改名字、岗位、提示词，或新增自己的角色

## 配置

- 设置里填店名、行业、DeepSeek API Key
- 不填 Key 是**演示模式**（预置示例回复），填了就是真实 AI 回答
- 数据：`~/.dsh/taicore/team-*.json`，全部本机

## 建议用法

- 周会：让店长+财务+投流开一次圆桌，议题「这个月钱怎么花」
- 上新：选品+文案+设计+投流，议题「上新品 X 怎么推」
- 危机：客服+店长，议题「差评怎么处理」
