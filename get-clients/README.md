# 钛核 · 获客工作台

给实体店、电商、自由职业者用的获客工具：**AI 出方案 + 批量文案 + 线索跟进**。

## 用之前说清楚

我们**不做**这些（会封号、也不合规）：
- 爬取平台用户数据
- 自动群发私信/短信

这里做的是：
1. **AI 帮你出获客方案**（客户画像、关键词、渠道、7 天清单）
2. **批量生成触达内容**（私信首条、朋友圈、点评回复、短视频钩子）
3. **线索跟进管理**（本地记录、状态流转、一键生成跟进话术、转化看板）

## 使用

1. 双击 `启动获客工作台.bat`
2. 浏览器打开 `http://127.0.0.1:8792`
3. 点右上角「模型设置」填入自己的 DeepSeek API Key（不填也能用，走内置模板）
4. 填行业/城市/客单价 → 生成方案
5. 把聊过的人加到「线索管理」，用状态流转跟踪

## 数据存哪

`~/.dsh/taicore/leads.json`（本地文件，不上传）

## 边界

- 方案和话术由 AI 生成，**发之前自己把关**，不要群发骚扰
- 平台规则以各平台为准，本工具只做内容生产与记录
