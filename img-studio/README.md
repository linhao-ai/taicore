# 钛核 · 一键出图

上传一张商品图 + 填文案 → 自动生成 4 张可直接上架的图。

## 出图规格

| 用途 | 尺寸 |
|---|---|
| 平台主图 | 800×800 |
| 通用主图 | 1080×1080 |
| 促销海报 | 1080×1440 |
| 方图带卖点 | 1080×1080 |

## 风格

- 简约白：通用、干净，适合大多数类目
- 促销红：冲量、活动，视觉冲击强
- 黑金：品质感、高客单

## 用法

1. 双击 `启动一键出图.bat`
2. 拖入商品图（白底或纯色底效果最好）
3. 填主标题、卖点（每行一条）、价格、促销标签
4. 选风格 → 生成 → 每张点「下载 PNG」

全部在浏览器本地合成，图片不上传。

## 说明

- 这是**模板合成**出图（排版 + 文案 + 商品图），不是 AI 绘画
- 需要 AI 生图（如即梦/可灵）可后续按需接第三方 API
