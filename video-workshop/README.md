# 钛核 · 视频工坊（本地版）

把门店照片 / 商品图 + 一段文案，自动生成带中文配音和字幕的短视频。**全程本地运行，不上传云端，零成本。**

## 快速开始

1. 双击 **视频工坊.bat**
2. 浏览器自动打开 `http://127.0.0.1:8790`
3. 拖入图片 → 每张图下面写一句文案 → 选比例 → 点「生成视频」
4. 生成完成后可直接预览、下载 mp4 和 srt 字幕

输出目录：`video/output/`（文件名形如 `钛核视频_xxxxxxxx.mp4`）

## 参数说明

| 参数 | 作用 |
|---|---|
| 画面比例 | 竖屏 9:16（抖音/视频号/小红书）、横屏 16:9（公众号/门店屏）、方屏 1:1（朋友圈/点评） |
| 语速 | -4（很慢）到 +4（很快），默认正常 |
| 背景音乐 | 可选，自动循环并压到 16% 音量，人声为主 |

## 生成规格

- 视频：H.264 / 1080p（竖屏 1080×1920、横屏 1920×1080、方屏 1080×1080）/ 30fps
- 音频：AAC 44.1kHz，系统中文语音（Microsoft Huihui，离线合成）
- 字幕：中文字幕居中烧录进画面，同时导出 `.srt`
- 每段时长 = 配音时长 + 0.45 秒停顿，最短 2.2 秒
- 画面：轻微推近（Ken Burns）+ 淡入淡出转场

## 技术要求

- Windows 10/11
- 自带 `bin/ffmpeg.exe`（已内置，无需另装）
- 需 Node 运行时（钛核安装目录自带的 vendor/node 即可，或系统 node）

## 常见问题

**Q：生成很慢？**
默认 `veryfast` 预设，30 秒视频约 15–25 秒出片。机器越新越快。

**Q：能改字幕字体/位置吗？**
当前固定黑体、底部居中、3px 描边。要改字体改 `lib/render.mjs` 里的 `FONT` 常量。

**Q：能批量生成吗？**
可以写脚本调用 HTTP 接口 `/api/render`，或多次在界面上操作。

**Q：能加片头和片尾吗？**
目前没做。可以把片头做成一张图放在第一段。

**Q：生成的视频有水印吗？**
没有。可以商用。

## 合规提示（重要）

内置的 `ffmpeg.exe` 是社区静态构建（含 libx264，**GPL 许可**）。对外分发时：

1. 在「开源许可」页面声明使用了 FFmpeg，并附 GPL v3 文本
2. 提供该二进制对应的源码获取方式（指向 https://ffmpeg.org 即可满足“书面报价提供源码”的常见做法，严谨起见附构建来源）
3. 我们通过**独立进程调用** ffmpeg（不链接进主程序），这是业界常见做法

若后续要更彻底规避，可换 **LGPL 版 FFmpeg + 硬件编码器**（h264_nvenc / h264_amf），但需要按机器 GPU 适配，工作量约 1–2 天。

## 目录结构

```
video/
├─ 视频工坊.bat        启动器
├─ server.mjs          本地服务（界面 + 接口）
├─ lib/render.mjs      合成管线（ffmpeg 滤镜、字幕、配音、混音）
├─ lib/tts.ps1         中文语音合成（Windows SAPI）
├─ public/index.html   界面
├─ bin/ffmpeg.exe      内置 ffmpeg（61MB）
├─ jobs/               中间文件（可定期清理）
└─ output/             成品视频
```
