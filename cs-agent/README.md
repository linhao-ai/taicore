# 钛核 · 智能客服

把店里的常见问题变成知识库，客户一问就能给出可复制的回复。

## 三种模式

| 模式 | 条件 | 效果 |
|---|---|---|
| 模板模式 | 不配 Key | 关键词检索知识库 + 兜底话术 |
| AI 模式 | 配 DeepSeek API Key | 按知识库生成自然回复，不编造 |

## 用法

1. 双击 `启动智能客服.bat`
2. 「设置」里填店名、语气、API Key（可选）
3. 「知识库」批量导入：每行 `问题 | 答案`
4. 或点「AI 生成 10 条常见问题」→ 全部导入
5. 平时「回复客户」里粘贴客户问题 → 生成 → 复制

## 数据

- 知识库：`~/.dsh/taicore/cs-kb.json`
- 设置：`~/.dsh/taicore/cs-settings.json`
- 全部本机，不上传

## 提醒

- AI 只依据你的知识库回答，不会凭空编造；知识库没有的会说"确认后回复"
- 回复建议发前自己过一眼，涉及价格/承诺以你为准
