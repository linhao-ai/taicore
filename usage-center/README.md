# 钛核 · 用量中心（本地）

查看 token 用量、估算费用、模型分布与账户余额。**只读本机数据，不上传任何服务器。**

## 快速开始

1. 双击 **StartUsageCenter.bat**
2. 浏览器打开 `http://127.0.0.1:8791`

## 数据来源

| 数据 | 来源 |
|---|---|
| 调用记录 / token 用量 | `%USERPROFILE%\.dsh\bot\usage.sqlite`（钛核内核写入，只读） |
| 模型单价 | 内置价格表（`server.mjs` 里的 `PRICES`），可按需修改 |
| 余额 | 模型厂商官方接口（如 DeepSeek `/user/balance`），Key 仅存本机 |
| 充值记录 | 厂商平台维护，本地无法读取；页面提供充值入口 |

## 功能

- KPI：Token 总量、估算费用、输入/输出、缓存命中
- 每日用量柱状图（今日 / 7 天 / 30 天 / 全部）
- 模型分布（按费用排序）
- 最近调用明细（时间、模型、输入、缓存、输出、估算费用）
- 余额查询：粘贴 API Key（保存到 `~/.dsh/taicore/provider-keys.json`）
- 充值入口：一键跳转厂商充值页

## 注意

- 费用为**估算值**，按公开单价折算，实际以厂商账单为准
- 缓存命中按低价计算，命中越多越省钱
- 本工具不代理模型请求，不接触你的对话内容

## 目录结构

```
usage-center/
├─ StartUsageCenter.bat   启动器
├─ server.mjs             本地服务（读取 sqlite + 余额查询）
└─ public/index.html      界面
```
